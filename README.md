# Abhay Kumar — Portfolio

A modern AI / Data Science / Engineering portfolio built with Next.js, TypeScript and Tailwind CSS.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel-ready

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
